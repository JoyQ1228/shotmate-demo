ShotMate · 运行说明

双击 index.html，用 Chrome 或 Edge 打开；保留同级 assets 文件夹。无需安装、联网或 API Key。

流程：灵感 → 新建计划 → 选择场景/氛围、填写想法和时长 → 生成 → 分镜拍摄 → 回看并保留 → 成片 → 分享/发布 → 社区拍同款。

分镜：未拍镜头在前，已拍镜头在后；已拍画面可点击播放；支持编辑、重拍、加入/排除成片。镜头偏短时自动更新下一镜头拍法。拍完会保留至“我的”。
我的：保存各个计划及独立素材，点击切换当前计划；新建与取消新建不会覆盖原计划。
社区：示例作品、播放、查看分镜、拍同款；发布仅存入当前浏览器演示社区。
状态：生成有加载与重试，空输入有提示；离开拍摄/播放页会停止计时；重拍确认保留之前不会覆盖旧素材。

模拟边界：AI 为本地模板与规则；相机为场景摄影；播放是照片运镜和切换，不是真实视频。分享支持作品名称，不导出视频。所有数据保存在当前浏览器，清除浏览器数据会删除记录。摄影来自 Unsplash。

验证：已运行自动流程检查，覆盖八类场景、时长分配、计划切换与隔离、取消新建、录制退出、单镜头回看、成片选择、社区发布去重与拍同款。尚未完成真实浏览器逐屏视觉验收。
